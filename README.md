# AutoLabel 3D — Landing Page

Landing page chính thức của **AutoLabel 3D** — Nền tảng tự động gán nhãn 2D Camera & 3D LiDAR cho xe tự lái và robotics với cơ chế Multi-signal QA Agent và Review by Exception.

## 🚀 Triển khai qua GitHub Pages
1. Tạo một repository mới trên GitHub (ví dụ: `autolabel-landing` hoặc `<username>.github.io`).
2. Tải toàn bộ các file trong thư mục này lên repository:
   - `index.html`: Trang đích với toàn bộ hiệu ứng 3D NotebookLM và điều hướng trực tiếp sang ứng dụng chính.
   - `landing.css`: Bộ stylesheet độc lập hỗ trợ Dark/Light mode chuẩn xác.
   - `demo_lidar_bev.png`: Ảnh sensor BEV 3D LiDAR.
   - `demo_camera_2d.png`: Ảnh Camera 2D đối tượng giao thông.
   - `favicon.svg`: Icon nhận diện thương hiệu.
3. Vào **Settings** > **Pages** của GitHub:
   - **Source**: Chọn `Deploy from a branch`
   - **Branch**: Chọn `main` (hoặc `master`) và thư mục `/(root)`
   - Nhấn **Save**.
4. Sau 1–2 phút, trang landing page sẽ hoạt động với URL dạng `https://<username>.github.io/<repo-name>/`.
